Bridge Box Mk1 — Helm + Relay deck for EmptyEpsilon

30 Aug 2026 — SXP 14:30, 2 Unos, OLED, joystick, 4x4 keypad

Wiring (Duponts off the breadboard)

  • Breadboard red = Uno 5V, blue = GND — all modules tap those rails
  • OLED 0.96" SSD1306 (GND VCC SCK SDA) -> GND blue, VCC red, SDA A4, SCL A5 — 0x3C, 6px XOFF
  • Joystick -> VRx A0, VRy A1, SW D2, VCC red, GND blue
  • 4x4 keypad -> R1-4 D6 D7 D8 D9, C1-4 D10 D11 D12 D13

Arduino

BridgeBox.ino on COM3 @115200 — modes RELAY <-> HELM via D, OLED shows MODE + Last key + Thr:ON/OFF Tur:ON/OFF. Libraries: U8g2 + Keypad.

Python bridge

bridge_box.py — auto-finds COM3, maps per mode:

  • Relay: 1 Red, 2 Yellow, 3 Reset (via Alert Level menu at 5), 0 Call FC — clicks with restore, A hold
  • Helm: joystick Up/Down Left/Right hold, 1 2 3 A 4 impulse 0/25/50/75/100% (slider clicks from helm_coords.txt), 5 6 B 7 8 warp 0-4, 9 thrust toggle, C turn toggle, 0 dock, click toggles impulse/warp

Helm impulse via clicks

Grabbed with grab_coords.py + F8 on the Helm slider — 1->44,650 etc. See helm_coords.txt.

python Coding\Python\BridgeBox\bridge_box.py
# cycle D, Helm 9/C for locks, 1-4 for impulse, 5-8 for warp

Keybindings patched in EmptyEpsilon/keybindings.json for HELMS_IMPULSE_* and WEAPONS_LOAD/FIRE_TUBE1-4.
